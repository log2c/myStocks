## 共通参数说明

### 市场编号（常用）

  1. `0`：深市（深交所，00/30/15开头）

## 批量查询实时行情

secids 基本格式
- 格式：**`市场编号.证券代码`**，多个用**半角逗号**分隔。
- 市场编号（常用）：
  - `0`：深市（深交所，00/30/15开头）
  - `1`：沪市（上交所，60/68/51开头）
  - `100`：指数（如 100.000001 上证指数）
  - `hk`：港股、`us`：美股（部分接口支持）

示例：

```
secids=1.600519,0.000001,1.510300
```

对应：贵州茅台(沪)、平安银行(深)、华夏上证50ETF(沪)
